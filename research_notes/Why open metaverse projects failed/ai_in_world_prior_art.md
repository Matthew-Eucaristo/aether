# Prior art: AI agents that act inside, build, or generate virtual worlds and game behavior (as of 24 Nov 2026)

Method note: about 15 searches and fetches, run on 24 Nov 2026. Items marked **[TK]** come from the researcher's training knowledge of primary papers published before mid-2026. Their URLs are canonical arXiv or official links that were not re-fetched in this session, so check them before quoting exact numbers. Several 2026 sources are SEO listicles or vendor blogs, and they are flagged as such.

## 1. Minecraft LLM agents: architecture, results, limitations, observation format

### Takeaway
The Minecraft agents that work best use code as the action space, with text observations rather than vision. Voyager writes Mineflayer JavaScript functions and stores verified functions in a skill library, so the LLM acts as a programmer and not as a frame-by-frame controller. That is the same split the founder proposes (the LLM writes code and the code runs in the tick loop). Multi-agent and civilization-scale work (Project Sid, MineCollab) shows that coordination, communication and coherence are the main bottlenecks, not single-agent skill.

### Cited Findings
- **Voyager (NVIDIA/Caltech et al., May 2023) [TK].** GPT-4 agent with three parts: (1) an automatic curriculum that proposes the next task from agent state and exploration progress; (2) a skill library of executable JavaScript (Mineflayer API) functions, indexed by an embedding of each function's description and retrieved for new tasks; (3) iterative prompting that feeds environment feedback, execution errors and a GPT-4 self-verification check back into code revision. A skill enters the library only after self-verification passes. Reported results: 3.3x more unique items, 2.3x longer travel distance, and tech-tree milestones up to 15.3x faster than prior state of the art, plus zero-shot transfer of the skill library to a new world. Observations are text (inventory, nearby blocks, biome, health), not pixels. — [arXiv 2305.16291](https://arxiv.org/abs/2305.16291); [repo](https://github.com/MineDojo/Voyager)
- **Voyager limitations [TK]:** it depends on GPT-4, since GPT-3.5 code generation was much worse in the ablations. Cost is high. Self-verification sometimes produces false successes. It has no vision, so it cannot judge building aesthetics. — [arXiv 2305.16291](https://arxiv.org/abs/2305.16291)
- **MineDojo (NeurIPS 2022) [TK].** A simulation suite with thousands of open-ended tasks and an internet-scale knowledge base: about 730K YouTube videos, about 7K wiki pages and about 340K Reddit posts. Trained MineCLIP, a video-text reward model, to score open-ended tasks. The approach is vision and RL, the opposite of Voyager's code and text. — [arXiv 2206.08853](https://arxiv.org/abs/2206.08853)
- **MINDcraft / MineCollab (arXiv Apr 2025; NeurIPS 2025 under the title "Blocks, Bots, and Bottlenecks").** A Mineflayer-based platform for multi-agent LLM play, with a benchmark of cooking, crafting and construction tasks. Agents talk in natural language. MINDcraft "primarily uses textual observations rather than visual inputs." Main finding: communication is the bottleneck. Performance drops by up to 15% when agents must spell out detailed step-by-step plans, and the authors call current LLM agents "ill-optimized for multi-agent collaboration" in embodied settings. — [arXiv 2504.17950](https://arxiv.org/html/2504.17950v1); [NeurIPS 2025](https://neurips.cc/virtual/2025/137194)
- **Mindcraft action design [TK]:** agents mostly call a fixed set of `!command` tools (for example go to player, collect blocks, craft). An optional mode lets the LLM write and execute arbitrary JavaScript. The README warns that this mode lets the LLM run code on the host, is "sandboxed but still vulnerable to injection attacks," and should not be connected to public servers. This was recalled from training knowledge, so check the current wording. — [github.com/mindcraft-bots/mindcraft](https://github.com/mindcraft-bots/mindcraft) (formerly kolbytn/mindcraft)
- **TickingCollabBench** (separate benchmark): LLMs "frequently fail under dynamic environments" because of latency and the difficulty of coordinating under partial observability. — summarized via search result linking [arXiv 2606.15684](https://arxiv.org/pdf/2606.15684). The PDF was not fetched, so the attribution is unverified.
- **Project Sid / Altera (arXiv Oct/Nov 2024).** Simulated 10 to 1000+ agents in Minecraft. Agents use the PIANO architecture (Parallel Information Aggregation via Neural Orchestration): concurrent modules for memory, action awareness, goal generation, social awareness, talking and skill execution, with a cognitive-controller bottleneck that keeps speech and action coherent **[TK for the module list]**. Reported emergent results: specialized roles, collective rules such as voting on a tax law, and religion spreading (the Pastafarianism meme). One summary says agents collectively gathered about 32% of all Minecraft items in more than 400 minutes. — [arXiv 2411.00114](https://arxiv.org/html/2411.00114v1); [repo](https://github.com/altera-al/project-sid); [MIT Tech Review, Nov 2024](https://www.technologyreview.com/2024/11/27/1107377/a-minecraft-town-of-ai-characters-made-friends-invented-jobs-and-spread-religion/amp/); [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/ai-created-a-minecraft-ai-village-with-up-to-1-000-inhabitants-project-sid-sees-ai-bots-implement-a-taxation-system-and-spread-pastafarianism-religion)
- **Project Sid limitations:** the authors say the work raises more questions than it answers, including how to measure long-term progress. Commentators cite goal obsession, communication breakdowns and stagnation. There is no independent replication, and critics ask whether the demo was tuned for its showcased outputs. — [arXiv 2411.00114](https://arxiv.org/html/2411.00114v1); [CryptoSlate](https://cryptoslate.com/entirely-ai-populated-civilization-develops-priest-led-cults-in-minecraft/)
- **Building benchmarks.** *MineAnyBuild* (2025): 4,000 curated tasks in which agents produce executable architecture build plans, evaluated on four dimensions of spatial planning. — [arXiv 2505.20148](https://arxiv.org/html/2505.20148v3). *APT* (late 2024): LLM agents construct creative structures. The authors note there is no standardized benchmark and propose criteria for instruction interpretation, creativity, rule adherence and use of visual input. — [arXiv 2411.17255](https://arxiv.org/abs/2411.17255v1). *T2BM* (2024): the LLM outputs a JSON-style block encoding and a repair step fixes it. GPT-3.5 and GPT-4 produce complete buildings aligned with instructions. — [arXiv 2406.08751](https://arxiv.org/html/2406.08751v1). *Minecraft Builder Dialog benchmark* (2024): text-based spatial reasoning. — [arXiv 2407.12734](https://arxiv.org/html/2407.12734v1). Long-running related venue: the GDMC (Generative Design in Minecraft) settlement-generation competition. **[TK]**

### Inferences
- Voyager is the closest existing proof of the "LLM writes code, code runs in the loop" idea. The skill library maps directly to a shared, versioned library of user-compiled "programs", but Voyager's skills had one author (one agent) and one world. Sharing skills across many untrusted users in a persistent world is untested.
- Text and structured observations dominate because they are cheap and precise. Vision is needed mainly to judge aesthetics in building tasks. A hybrid approach makes sense: structured scene graph for planning, optional render or screenshot for critique.
- Multi-agent results imply that the world, not LLM chat, should be the coordination substrate. Shared state, explicit contracts and events between programs are more reliable than agents negotiating in natural language.

### Gaps
- No 2026 Minecraft building benchmark surfaced. Current state-of-the-art numbers on MineAnyBuild for 2026 frontier models were not found.
- Altera's post-Sid direction is unverified. The researcher recalls a 2025 pivot toward productivity agents but did not confirm it.
- No per-action cost figures were found for Voyager or Mindcraft in this session.

## 2. Generative world models (Genie 2/3/4, Oasis, Muse/WHAM, GameNGen) compared with code-based engines

### Takeaway
As of November 2026, neural world models render impressive single-player, short-horizon interactive video. None offers durable persistent state, multiplayer consistency, deterministic rules or cheap per-user compute. Project Genie still caps sessions at 60 seconds because of compute cost, and memory is about a minute. For a persistent, shared, multi-user world they are at best a rendering, preview or "dreaming" layer, not a substrate. That confirms a code-plus-assets engine as the source of truth.

### Cited Findings
- **Genie 1 (Feb 2024):** 11B parameters, 2D platformer worlds at about 1 fps, trained without action labels on 30K hours of footage. **Genie 2 (Dec 2024):** 2D/3D worlds at 360p, consistent for about 10 to 20 seconds. **Genie 3 (Aug 2025):** real time at 720p/24 fps, with about one minute of visual memory and text-promptable world events. — [Wikipedia: Genie (world model)](https://en.wikipedia.org/wiki/Genie_(world_model))
- **Project Genie (29 Jan 2026):** Google Labs web app for AI Ultra subscribers. Exploration is capped at 60 seconds because the autoregressive model is compute-intensive. DeepMind said longer sessions would add little testing value at higher cost. Video-game stocks fell the next day. Street View grounding and worldwide Ultra availability followed in May/June 2026, though sources disagree on the date (19 May vs 6 June). Reviewers called 24 fps "too choppy" (Fast Company) and performance slow (The Verge). — [Wikipedia](https://en.wikipedia.org/wiki/Genie_(world_model)); [Towards AI](https://newsletter.towardsai.net/p/tai-190-genie-3-world-model-goes)
- **Genie 3 in practice:** no objectives, scoring, progression, multiplayer or persistence. A world that exists only inside one GPU inference session cannot hold saves or a campaign. Multiple agents in one generated world produce coordination failures. (Secondary blog, not primary.) — [StraySpark blog](https://www.strayspark.studio/blog/genie-3-world-model-vs-game-engines-2026)
- **Genie 4 (announced 27 Oct 2026):** adds native audio (ambient sound, music, dialogue), live natural-language steering (camera, weather, adding characters), and claimed physics such as aerodynamics and collisions. It draws on Gemini Omni for real-world grounding and on other Gemini models for coherence and continuity. Rollout began with trusted testers and is "coming soon" to Project Genie and early-access Gemini API/AI Studio partners. The post states **no** resolution, fps, memory duration, session length, multiplayer support, persistence, latency or pricing. One secondary source claims API access expanded on 18 and 19 Nov 2026, which is unverified. Intended uses are agent and robot training, film, journalism, gaming and manufacturing. — [Google blog, 27 Oct 2026](https://blog.google/innovation-and-ai/models-and-research/google-deepmind/introducing-genie-4/); [DataStudios](https://www.datastudios.org/post/google-deepmind-genie-4-real-time-world-model-native-audio-research-preview)
- **Waymo World Model (Feb 2026)** is built on Genie 3 to simulate robotaxi edge cases. It shows that world models' strongest commercial fit so far is simulation and training data, not games. — [Wikipedia: Genie](https://en.wikipedia.org/wiki/Genie_(world_model))
- **GameNGen (Google, Aug 2024) [TK]:** a diffusion model that runs DOOM at about 20 fps on a single TPU. Next-frame PSNR is about 29.4, comparable to lossy JPEG. Human raters were only slightly better than chance at telling short clips from the real game. Context covers only a few seconds of frames, so state outside that window (for example, off-screen enemies or items) can be forgotten. — [arXiv 2408.14837](https://arxiv.org/abs/2408.14837)
- **Oasis (Decart + Etched, 31 Oct 2024) [TK for specs]:** an open-weights (~500M) real-time diffusion "Minecraft" world model at 360p, about 20 fps on an H100. Etched pitched its Sohu ASIC as the way to scale it. Reviewers found it low-resolution and glitchy, with poor object permanence. It "doesn't store data from your world" and forgets what you did. — [The Batch](https://www.deeplearning.ai/the-batch/ai-creates-an-interactive-minecraft-like-world-in-real-time); [PC Gamer](https://pcgamer.com/software/ai/ai-generated-minecraft-unveiled-showcasing-ais-unlimited-ability-to-copy-things-but-worse); [Decart/Oasis site](https://oasis-model.github.io/)
- **Muse / WHAM (Microsoft Research + Ninja Theory, Nature, Feb 2025) [TK]:** World and Human Action Model trained on about 7 years of *Bleeding Edge* multiplayer gameplay. Evaluated on consistency, diversity and persistency, where persistency means user-edited objects persist. Pitched for ideation, not shipping games. WHAMM, a real-time Quake II demo in Copilot Labs (Apr 2025), had a short context of about 1 second, fuzzy enemy interactions and poor numeric tracking (health, ammo). — [Nature](https://www.nature.com/articles/s41586-025-08600-3); [Microsoft Research blog](https://www.microsoft.com/en-us/research/blog/introducing-muse-our-first-generative-ai-model-designed-for-gameplay-ideation/)
- **Research consensus on the weakness:** compounding errors and insufficient memory are the core limits of interactive world models. — [arXiv 2505.22976](https://arxiv.org/html/2505.22976v1). The MIND benchmark (Feb 2026) finds spatial memory consistency "far from satisfactory" across four baseline Minecraft world models. — [arXiv 2602.08025](https://arxiv.org/html/2602.08025v1). Long-horizon work continues, for example AlayaWorld (Jul 2026). — [HF papers 2607.06291](https://huggingface.co/papers/2607.06291.md). The survey "From Masks to Worlds" notes that high-quality generation comes at substantial cost. — [arXiv 2510.20668](https://arxiv.org/html/2510.20668v1)
- **Platforms are hedging:** Roblox has a "real-time dreaming" world-model research project in early development, demoed by CEO David Baszucki with no date. Its shipping product is the Cube asset/behavior model on top of the conventional engine. — [Roblox newsroom, Feb 2026](https://about.roblox.com/newsroom/2026/02/accelerating-creation-powered-roblox-cube-foundation-model)

### Inferences
- **Persistence.** World models hold state implicitly in activations or context, which decays within seconds to minutes. A code engine holds explicit state that can be serialized, diffed and backed up. A persistent world needs the latter.
- **Multiplayer.** A world model renders per viewer. Two players' GPU sessions would diverge unless a shared authoritative state is fed back as conditioning, and at that point the authoritative state is the engine.
- **Cost.** About one GPU per concurrent user per session, versus one server tick loop shared by many users plus client-side rendering. Genie's 60-second cap is the clearest public signal of the cost problem.
- **Determinism and rules.** Game rules such as inventory counts, damage and economy cannot be guaranteed by a generative model (see WHAMM's numeric tracking). The founder's design keeps rules in verifiable code.
- **Plausible roles for world models** in the founder's design: (a) previewing or "dreaming" a user's intent before compiling it into code; (b) stylized rendering filters on top of engine state; (c) generating training or reference data. Genie 4's text-steerable events are a useful UX reference for intent capture.

### Gaps
- Genie 4 technical specs (fps, memory, session length) were not published in the primary post. They were not found.
- No public per-hour inference cost for Genie, Oasis or WHAMM was found.
- No world model with documented shared multiplayer state was found. Absence in these searches is not proof that none exists.

## 3. Platform AI creation tools (Roblox, Meta Horizon, Unity, Rosebud, UEFN, prompt-to-game), 2025–2026

### Takeaway
Shipped tools fall into two classes. (a) Engine-integrated agents (Roblox Assistant with MCP and agentic planning/playtesting, Meta Creator Assistant, Unity AI) edit a conventional project. (b) Runtime "4D" generation (Roblox Cube 4D) lets players spawn functional objects in-world by constraining AI output to predefined schemas with pre-written, retargeted scripts. Class (b) is the closest commercial analogue to the founder's design, and it deliberately avoids letting AI write arbitrary runtime code. Full prompt-to-game builders (Rosebud etc.) produce browser prototypes but are not production-grade.

### Cited Findings
- **Roblox Cube 3D** (Mar 2025): proprietary foundation model producing textured 3D objects from text inside Studio. — [Game Developer](https://www.gamedeveloper.com/business/roblox-announces-ai-powered-object-scene-creation-model); [Wikipedia: Cube 3D](https://en.wikipedia.org/wiki/Cube_3D). Cube 3D weights were open-sourced in 2025. **[TK, unverified this session]**
- **Roblox 4D generation** (early access Nov 2025; open beta 4 Feb 2026): players type a prompt in an experience and get a functional object, for example a drivable car. It works through **schemas**, rulesets that split an object into named parts and attach behaviors. Launch schemas were *Car-5* (body plus four wheels, with scripts that spin and steer wheels) and *Body-1* (any single mesh). A **retargeting step** adapts attached scripts to each generated object's dimensions. Planned: an open-vocabulary schema system and schemas covering thousands of real-world objects. Results: more than 160,000 objects generated in early access, and in *Wish Master* players using it averaged 64% more play time. Players asked for things that do not exist or phrased wishes unexpectedly, so interpreting requests is ongoing work. The post says nothing about safety or moderation. — [Roblox newsroom, Feb 2026](https://about.roblox.com/newsroom/2026/02/accelerating-creation-powered-roblox-cube-foundation-model); [TechCrunch](https://techcrunch.com/2026/02/04/robloxs-4d-creation-feature-is-now-available-in-open-beta/)
- **Roblox Studio "going agentic"** (15 Apr 2026): 44% of the top 1,000 creators used Assistant or third-party AI via MCP (6 Mar to 7 Apr 2026). **Planning Mode** analyzes code and the data model, asks clarifying questions, and produces an editable action plan that works as a mini design document and task manifest. Cross-session storage of that context is "soon," not shipped. **Playtesting Agent (beta)** checks the game against the plan by reading code, the data model and logs, and drives the player character as an automated QA tester. Results feed back into planning as a "self-correcting" loop. Procedural (code-controlled, parameterized) models are announced, not shipped. Studio has a built-in MCP server that third-party tools can use (Claude, Cursor, Codex are named). The post mentions no undo/checkpoint or guardrail features. — [Roblox newsroom, Apr 2026](https://about.roblox.com/newsroom/2026/04/roblox-studio-going-agentic)
- **Roblox Studio MCP** lets an external AI client explore the data model, write scripts, run Luau and test in play mode over stdio. Earlier open-source tools included `run_script_in_play_mode`, which stops after the script finishes or times out. — [Roblox docs: Studio MCP](https://create.roblox.com/docs/studio/mcp); [DevForum](https://devforum.roblox.com/t/studio-mcp-server-updates-and-external-llm-support-for-assistant/4415631)
- **Meta Horizon.** The Desktop Editor reached early access in Feb 2025 and was renamed **Horizon Studio** (announced Sept 2025). Generative features include meshes, textures, skyboxes, SFX and ambient audio, TypeScript and islands, and they are region-limited. **Creator Assistant** (Aug 2025) is agentic: "make a door that opens when a button is pressed" makes it find library assets, place them, set properties and write TypeScript. However, it *cannot* call the generative tools and only searches existing assets. The planned Horizon Studio assistant would generate whole worlds, assets and mechanics, plus custom NPCs. Conversational NPCs can receive world-state context and live events, but are limited to US adults. **Horizon Engine** replaces Unity as the runtime and claims 4x faster loading and 100+ users per instance. UploadVR says most of this was promises at the time. — [UploadVR, 18 Sep 2025](https://www.uploadvr.com/meta-horizon-studio-upgrade-ai-assistant-horizon-worlds/); [UploadVR: environment generation teaser](https://www.uploadvr.com/meta-teases-ai-generation-of-entire-horizon-worlds-coming-very-soon/); [Meta developers](https://developers.meta.com/horizon-worlds/)
- **Meta WorldGen** (research): text-to-3D world generation. UploadVR asked why it was not yet in the editor. — [UploadVR](https://www.uploadvr.com/meta-worldgen-ai-generates-3d-worlds/)
- **Unity AI**: open beta in May 2026 and still labeled beta in Sept 2026. It is an engine assistant, not a game generator. — [Cinevva guide](https://app.cinevva.com/guides/ai-game-generators-2026) (secondary)
- **Rosebud AI**: described as the strongest prompt-to-playable-game tool and strongest in 2D. Games live in the browser, so it is "not worth it if you want to ship to Steam, build real 3D, or own a project file you can move." — [SummerEngine review](https://www.summerengine.com/blog/is-rosebud-ai-worth-it) (secondary, possibly a competitor); [Unite.AI Nov 2026 list](https://www.unite.ai/best-ai-game-generators/)
- Useful taxonomy: "prompt-to-game builders" versus "engine-integrated AI agents." — [Cinevva](https://app.cinevva.com/guides/ai-game-generators-2026)

### Inferences
- Roblox 4D's schema-plus-retargeted-script pattern is a strong template. The AI chooses and parameterizes from a vetted behavior vocabulary instead of emitting free-form tick-loop code. The founder could offer a tiered capability model: schema-constrained generation for anonymous or untrusted users, and free-form sandboxed code for trusted creators or after review.
- Roblox's plan, then build, then playtest-agent-feeding-back-into-plan loop is the current industry reference harness for "compile intent into code."
- Meta's Creator Assistant gap (an agent that could not call the generators) is an integration lesson: expose generation, placement and scripting as one tool surface to a single agent.

### Gaps
- No search results on Fortnite UEFN AI features for 2025–2026. Epic's Persona Device / AI NPC tools (the Darth Vader voice NPC, May 2025 **[TK]**) and any Verse-generation assistant were not verified.
- No independent quality evaluation of Roblox Assistant or Horizon Studio output was found, only vendor stats and press.
- Whether Horizon Studio's full world generation shipped in 2026 is unconfirmed.

## 4. Text- and image-to-3D asset generation in 2026

### Takeaway
Hosted text- and image-to-3D (Meshy, Tripo, Rodin, Hunyuan3D 3.x) produces usable textured PBR props in roughly 15 seconds to 3 minutes. Open-weight options (TRELLIS.2 under MIT; Hunyuan3D 2.1 under a restrictive community license) allow self-hosting. Quality rankings depend on the use case and come mostly from vendor or listicle sources. No independent benchmark with measured numbers was found.

### Cited Findings
- Generation times: Meshy 30–90 s, Tripo 25–100 s, Rodin 2–3 min, TRELLIS.2 about 15–30 s (self-hosted). — [Fuser](https://fuser.studio/articles/best-ai-3d-model-generators); [3DAIStudio](https://www.3daistudio.com/blog/best-3d-model-generation-apis-2026) (via search summaries)
- Quality: Hunyuan3D V3 gives the smoothest, cleanest body, while TRELLIS.2 stays closest to the reference photo. Rodin Gen-2.5 is the pick for production PBR and 4K textures. Meshy (v7.1) is called the best all-rounder for game-ready assets. Tripo (H3.1) is the cheapest hosted option. — [Inker](https://inker.si/blog/best-ai-3d-model-generators-2026); [RapidDirect](https://www.rapiddirect.com/blog/best-8-ai-3d-model-generators/); [Trify3D](https://trify3d.com/blog/best-ai-3d-model-generators) (listicles; treat as opinion)
- Licensing: TRELLIS.2 code and model are MIT, image input only (no text-to-3D). Hunyuan3D 2.1 uses the Tencent Community License with territory restrictions. Hunyuan3D 3.1 appears API-only. Sources conflict on TRELLIS.2 output: Gaussian splats versus textured PBR GLB. — [Cinevva](https://app.cinevva.com/guides/ai-3d-model-generators); [3DAIStudio](https://www.3daistudio.com/blog/best-3d-model-generation-apis-2026)
- Rigging and animation: Meshy and Tripo offer automatic humanoid rigging and preset animations **[TK; not verified this session]**. Roblox sidesteps arbitrary rigging with schemas that require segmented meshes (for example, separate wheels). — [Roblox newsroom](https://about.roblox.com/newsroom/2026/02/accelerating-creation-powered-roblox-cube-foundation-model)

### Inferences
- An open-source world needs a license-clean pipeline. TRELLIS.2 (MIT) as image-to-3D, fed by a text-to-image step, is the obvious self-hostable path. Hunyuan's license may conflict with open-source distribution in some territories.
- A latency of 15 seconds to 3 minutes per asset means in-world creation needs a placeholder or proxy (a grey box or similar library asset) placed immediately and swapped when the mesh is ready.
- Functional objects need part-segmented, named meshes, not single blobs. That is a requirement on the generator and on post-processing, as in Roblox's Car-5 schema.

### Gaps
- No independent quantitative benchmark (geometry accuracy, topology quality, polycount) for 2026 tools was found.
- State of non-humanoid auto-rigging and text-to-animation in 2026 was not verified.
- Moderation and IP filtering of generated meshes was not researched.

## 5. NPC and character AI: Inworld, NVIDIA ACE, Stanford Generative Agents

### Takeaway
Shipping NPC systems separate fast tick-rate control from slow LLM reasoning. KRAFTON's PUBG Ally runs a behavior tree at tick rate while an on-device 2B small language model handles intent and speech. This independently validates "the LLM never runs inside the tick loop." Generative Agents' memory stream, reflection and planning remain the reference cognitive architecture, but they are expensive. Inworld shifted from game NPCs toward general runtime and voice infrastructure.

### Cited Findings
- **Generative Agents / Smallville (Stanford and Google, Apr 2023) [TK]:** 25 agents in a sandbox town. Architecture: a **memory stream** of natural-language observations, **retrieval** scored by recency, importance (LLM-rated) and relevance (embedding similarity), periodic **reflection** that synthesizes higher-level memories, and recursive **planning** from day plans down to minute actions. Emergent behavior includes a Valentine's Day party that spread by word of mouth. Ablations show each component improves believability. Limitations: cost (the authors report simulating 25 agents for two days cost thousands of dollars in API credits), memory-retrieval failures, embellishment or hallucination, and overly formal or cooperative behavior from instruction tuning. — [arXiv 2304.03442](https://arxiv.org/abs/2304.03442)
- **NVIDIA ACE:** the on-device stack is ASR, then a small language model, then TTS. The SLM receives the transcribed request plus a textual description of match state. **KRAFTON PUBG Ally:** cloud LLMs "often made responses feel too slow for live squad communication." A local 2B model removed the network round-trip. A behavior tree handles movement and combat at tick rate, and the SLM handles intent, coordination and speech. It targets GPUs with 8 GB VRAM. — [NVIDIA dev blog: PUBG Ally](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/); [NVIDIA blog: on-device SLM](https://blogs.nvidia.com/blog/ai-decoded-gamescom-ace-nemotron-instruct)
- **ACE Game Agent SDK plus UE5 plugins** (Unreal Fest 2026): local GGUF inference with function calling, shipped with Qwen 3.5 4B. — [NVIDIA dev blog](https://developer.nvidia.com/blog/build-on-device-ai-companions-with-the-nvidia-ace-game-agent-sdk-and-unreal-engine-5-plugins/). No clean 2026 latency numbers were found.
- **Inworld:** launched Inworld Runtime (Aug 2025) as a general "AI runtime for consumer applications." Runtime carries over Studio's knowledge retrieval, safety checks, long-term memory and voice as composable pieces. In 2026 the company cut voice pricing (Jun) and released Realtime TTS-2 (Aug). *Death by AI* reportedly reached profitability after moving to Inworld from costlier AI services. — [GlobeNewswire, Aug 2025](https://www.globenewswire.com/news-release/2025/08/13/3132320/0/en/inworld-runtime-the-first-ai-runtime-for-consumer-applications.html); [Inworld docs](https://docs.inworld.ai/guides/runtime-character); [Contrary Research](https://research.contrary.com/report/inworld-ai)
- **Horizon NPCs** take world-state background plus dynamic event knowledge, and are limited to US adults. — [UploadVR](https://www.uploadvr.com/meta-horizon-studio-upgrade-ai-assistant-horizon-worlds/)

### Inferences
- The fast/slow split (behavior tree or compiled code at tick rate, LLM asynchronously setting goals and parameters) is now the production pattern. The founder's design extends it: the LLM produces the fast-path code itself.
- Generative Agents' cost argues for event-driven, sparse LLM invocation (only on user intent or salient events), not per-tick or per-agent polling.
- Inworld's pivot suggests that "AI NPCs for games" alone was a hard business. Value moved to infrastructure (voice, runtime). This is relevant to sustainability planning for an open-source world.

### Gaps
- No public per-conversation or per-NPC-hour cost figures for ACE or Inworld in 2026.
- No shipped game with LLM NPCs at MMO scale was verified.

## 6. Agent harness design lessons (tools, world-state context, verification, sandboxing, preview/undo, latency, cost)

### Takeaway
The converging harness pattern has five parts: structured text observations of world state; code as the action space; a library of verified, reusable skills; plan, execute, verify loops that use execution errors, logs and automated playtesting as feedback; and constrained schemas for untrusted users. Undo/checkpoint and spatial-context management are under-documented in public prior art and are open problems.

### Cited Findings
- **Code as the action space plus a skill library plus feedback loops** (Voyager): the environment returns execution errors and state, and self-verification gates skill storage. — [arXiv 2305.16291](https://arxiv.org/abs/2305.16291) [TK]
- **Plan before acting:** Roblox Planning Mode asks clarifying questions, produces an editable plan before any change, and keeps a task manifest for the session. Cross-session memory is still pending. — [Roblox, Apr 2026](https://about.roblox.com/newsroom/2026/04/roblox-studio-going-agentic)
- **Automated verification by playtest:** the Roblox Playtesting Agent reads code, the data model and logs, and drives the player character against the plan. The MCP tool `run_script_in_play_mode` has a timeout. — [Roblox, Apr 2026](https://about.roblox.com/newsroom/2026/04/roblox-studio-going-agentic); [Roblox MCP docs](https://create.roblox.com/docs/studio/mcp)
- **Constrain the output space:** Roblox 4D schemas plus script retargeting. — [Roblox, Feb 2026](https://about.roblox.com/newsroom/2026/02/accelerating-creation-powered-roblox-cube-foundation-model). T2BM generates a structured block encoding, then repairs it. — [arXiv 2406.08751](https://arxiv.org/html/2406.08751v1)
- **Tool-surface fragmentation hurts:** Meta's Creator Assistant could not reach the generative tools. — [UploadVR](https://www.uploadvr.com/meta-horizon-studio-upgrade-ai-assistant-horizon-worlds/)
- **Latency:** cloud LLM round-trips are too slow for live interaction (KRAFTON), so they are handled by local SLMs plus tick-rate behavior trees. — [NVIDIA/KRAFTON](https://developer.nvidia.com/blog/how-krafton-built-pubg-ally-a-co-playable-character-powered-by-nvidia-ace/). Latency and partial observability break LLM collaboration in dynamic environments. — [TickingCollabBench via arXiv 2606.15684](https://arxiv.org/pdf/2606.15684) (unverified attribution)
- **Context for large world state:** Minecraft agents use local text summaries (inventory, nearby blocks) rather than the full world. — [MINDcraft](https://arxiv.org/html/2504.17950v1). Roblox Assistant reads the "code and data model" (the scene tree). — [Roblox](https://about.roblox.com/newsroom/2026/04/roblox-studio-going-agentic)
- **Cost signals:** Genie sessions are capped at 60 s for compute reasons. — [Wikipedia](https://en.wikipedia.org/wiki/Genie_(world_model)). Generative Agents cost thousands of dollars for 25 agents over two days. — [arXiv 2304.03442](https://arxiv.org/abs/2304.03442) [TK]. Death by AI only became profitable after switching vendors. — [Contrary](https://research.contrary.com/report/inworld-ai)

### Inferences
- **Context:** give the harness a queryable spatial index (region, chunk or octree, plus a scene graph with semantic tags) as tools, for example "what is within 10 m of the user's gaze," rather than dumping state into the prompt. Combine with on-demand rendered views for aesthetic critique. Public systems only show local-window summaries, so scalable scene summarization for a shared world is an open problem.
- **Verification pipeline** for compiled code: static checks (types, capability manifest), a deterministic dry run in a forked or shadow world tick, automated playtest against the user's stated intent, and resource-budget measurement (CPU per tick, memory, entity count) before promotion to the live world.
- **Preview and undo:** because the LLM output is code plus assets (explicit state), every compile can be a transactional diff with ghost preview, commit and revert. This is a structural advantage over world models. No public prior art documents in-world undo for AI edits; Roblox's post is silent on it.
- **Latency budget:** treat intent-to-artifact as asynchronous (seconds to minutes; 3D generation is 15 s to 3 min). Give immediate feedback with placeholders and progress, and keep everything per-tick in compiled code.
- **Skill library as a commons:** Voyager's skill library generalizes to a shared, versioned, reviewed registry of compiled behaviors that the harness retrieves before writing new code. That cuts cost and risk.

### Gaps
- No public latency or cost-per-action data for Roblox Assistant, Horizon Studio or Unity AI.
- No published design for spatial indexing or scene summarization aimed at LLM harnesses in persistent multi-user worlds was found.

## 7. Safety: AI-generated in-world code, prompt injection from in-world content, AI-assisted griefing

### Takeaway
Prompt injection against game LLMs is demonstrated and unsolved: system-prompt prohibitions do not prevent leaks. Projects that let LLMs execute generated code in multiplayer games (Mindcraft) warn against public deployment. The only shipped runtime AI-generation system for players (Roblox 4D) avoids free-form generated code altogether. Indirect injection through in-world content (signs, item names, chat, other users' code) that a harness reads is the main unstudied threat.

### Cited Findings
- "Tricking LLM-Based NPCs into Spilling Secrets" (Aug 2025): 30 handcrafted injections (direct, social engineering, instruction override). 3 of 30 extracted a secret, and leakage happened even with an explicit system-level prohibition. — [arXiv 2508.19288](https://arxiv.org/html/2508.19288v1)
- Tensor Trust: a game-derived dataset of prompt-injection attacks showing a wide range of strategies. — [arXiv 2311.01011](https://arxiv.org/pdf/2311.01011). AgentDojo: small changes in injection phrasing swing success rates widely in tool-using agents. — [arXiv 2406.13352](https://arxiv.org/pdf/2406.13352)
- Mindcraft's code-execution mode is flagged as injection-vulnerable and not for public servers. — [GitHub](https://github.com/mindcraft-bots/mindcraft) [TK; verify current wording]
- Roblox 4D: player-triggered generation restricted to schemas with pre-authored, retargeted scripts. No moderation details are published. — [Roblox, Feb 2026](https://about.roblox.com/newsroom/2026/02/accelerating-creation-powered-roblox-cube-foundation-model)
- Genie/Project Genie refuses nudity, copyrighted characters and similar content at the content-filter level. — [Wikipedia](https://en.wikipedia.org/wiki/Genie_(world_model))
- Horizon conversational NPCs are restricted to US adults, a policy-level mitigation. — [UploadVR](https://www.uploadvr.com/meta-horizon-studio-upgrade-ai-assistant-horizon-worlds/)

### Inferences
- **Threat model for the founder's design:** (1) A user deliberately asks the harness for griefing code, such as lag machines, spam, traps, scraping other players' data or economic exploits. Minecraft command-block and redstone lag-machine history is the analogue, though it is unsourced here. (2) Indirect prompt injection: the harness reads world state containing adversarial text (sign text, object names, scripts written by others) and is steered. (3) Generated code that escapes the sandbox or exhausts the shared tick budget. (4) Generated assets that violate content or IP rules.
- **Mitigations implied by prior art:** capability-based sandbox with no ambient authority (code can touch only the owner's region and objects unless granted); per-script CPU, memory and entity quotas enforced by the runtime, not the LLM; deterministic replayable execution for audit; treat all world text as untrusted data in the harness prompt (quote or escape it, and never let it grant permissions); schema-constrained generation as the default tier; human or automated review before code affects other users' space; provenance, signing and instant revert of any compiled artifact.
- Safety must be enforced by the engine and runtime (rule 4: never rely on the LLM to refuse). Because the LLM is outside the tick loop, safety reduces to classic sandboxing of untrusted code plus moderation of a compile step. That is a better-understood problem than policing a live LLM.

### Gaps
- No research found on indirect prompt injection via in-world user-generated content against building or creation agents specifically.
- No public incident reports of AI-assisted griefing on Roblox or Horizon were found in this session.
- No published sandboxing design for AI-generated scripts on Roblox, Horizon or Minecraft was found. Roblox's Luau sandbox and Horizon's TypeScript runtime exist but were not researched here.
